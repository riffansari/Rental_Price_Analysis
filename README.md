# Rental_Price_Analysis
The project involves statistical analysis of 358 two-bedroom rental properties in Abu Dhabi to identify factors affecting prices of rental properties. 

Using Multiple Linear Regression in Python, the project answers one main research question;
### To what extent are location, floor size and number of bathrooms associated with the rental prices of two-bedroom properties in Abu Dhabi?


## Analysis Performed
Data cleaning and preparation
Descriptive statistics
Correlation analysis
Hypothesis testing using t-test
Multiple linear regression
Multicollinearity analysis using VIF
